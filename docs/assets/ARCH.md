# Architecture

Website UI scripts/styles and attributed measurements. `bun run build` copies the versioned DataView bundles from `dist/` into `defuss-dataview@<version>/` through `scripts/site-build.mjs`, which also removes older versions; they are excluded from lint. site.js uses the current local query module; metrics are refreshed after verification.

compute.js runs the compute section on its own, so a failure there leaves the rest of the page working. It imports `browser-compute.mjs` through the page's import map, pinned by hash like the main bundle; that bundle also exports the stream sources, because a source and a plan from two separate bundles would not share the private registries that let a plan lease prepared columns. site.js also runs compute plans in the query explorer: a request with an `aggregate`, `rows` or `view` key goes to `forRows()`, loaded on the first plan, so a failure there leaves descriptor queries working. json.js highlights JSON and the short JavaScript samples the page shows. mongodb.json and mongodb-compute.json hold the latest MongoDB comparisons at 100,000 and 1,000,000 documents; `bun run benchmark:mongodb` and `bun run benchmark:mongodb-compute` rewrite them.
